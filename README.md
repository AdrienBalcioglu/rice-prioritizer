# RICE Prioritizer

Score and rank features with RICE or ICE, in the browser.

## Features

- RICE (Reach × Impact × Confidence ÷ Effort) and ICE (Impact × Confidence × Ease) scoring
- Ranking and bars update as you type
- CSV export of the ranked list
- Saved locally, with sample data to start from

## Usage

Open `index.html` in a browser. There is nothing to install and nothing to build.

Your data is saved in the browser's local storage and never leaves your machine.

## Stack

HTML, CSS and JavaScript in a single file. No dependency.
